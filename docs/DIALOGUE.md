# 회화(다이얼로그) — 인도네시아어앱

**공통 원칙(2026-11-02 확정)**: https://talkverse.uk/talkverse/dialogue-rules/ — 회화를 만들거나 고칠 때 이것을 따른다.
절벽 기준표: https://talkverse.uk/cliff/18/
이 문서에는 인도네시아어 특이점만 적는다.

## 1. 기본 변이

- 기본 = **인도네시아어 표준어(bahasa baku)**, 회화 말투는 자카르타 구어를 참고(gue/lo 같은 속어는 R3 이상에서 note 로만).
- 말레이어(Bahasa Melayu Malaysia)는 **별도 파일**로 둔다(원칙 §11). 지금 데이터는 턴 안 `ms` 필드로 병기돼 있어 옮겨야 한다 → §5.

## 2. 성별판

- 인도네시아어는 동사·형용사·대명사에 문법 성별이 없다(dia = 그/그녀). **한 판만** 만든다.
- 호칭만 상대 성별에 따라 바뀐다: 손윗 남성 Mas·Bapak(Pak), 손윗 여성 Mbak·Ibu(Bu). 학습자 성별과 무관하게 상대역에 맞춰 쓴다.

## 3. 턴 길이 (원칙 §4 — 언어별)

단어 수 = 공백으로 나눈 낱말 수(중첩어 `teman-teman` 은 1).

| 구간 | 한 턴 단어 수 | 비고 |
|---|---|---|
| R1 | 3~8 | 1~2단어 단답 금지(인사 관용구 `Apa kabar?` 같은 2단어는 다른 문장과 한 턴으로) |
| R2 | 4~12 | |
| R3·R4 | 4~16 | |

(지금 데이터: ep1·ep2 평균 5.3~5.4, 최대 9 — R1·R2 기준 안.)

## 4. 한글 독음 표기표 (원칙 §7 — `rd` 칸, 초안 2026-11-02)

학습용 발음 표기다(국립국어원 외래어 표기법과 다를 수 있음). 원어민 검수 전 초안.

| 철자 | 독음 | 예 |
|---|---|---|
| a i u o | 아 이 우 오 | `ada` 아다 |
| e (약한 e, ə) | 으 | `terima` 뜨리마 |

| p t k (첫소리) | ㅃ ㄸ ㄲ — 숨이 안 나오는 소리 | `kamu` 까무, `tidak` 띠닥 |
| b d g j | ㅂ ㄷ ㄱ ㅈ | `baik` 바익 |

| h (끝소리) | 흐 (작게) | `rumah` 루마흐 |

| l | ㄹ, 모음 사이는 ㄹㄹ | `pulau` 뿔라우 |

## 5. 지금 데이터와 원칙의 차이 — 할 일

1. L1(ep1·ep2, 80턴)을 R 구간으로 다시 태그하고, 40턴 에피소드를 원칙 §3 길이(R1 6~8턴)의 편 여러 개로 나눈다.
2. 모든 턴에 `rd`(한글 독음) 추가 — 지금 없음.
3. 턴의 `ms` 필드를 `assets/data/dialogues/ms/` 별도 파일로 옮기고 앱의 MS 토글이 그 파일을 읽게 한다(앱 코드 변경 필요).
4. 편마다 반전 1회(`twist`), 수위 `flags[]`, `purpose[]`·`domain[]` 태그 — 기존 연애 서사는 `love` 도메인.
5. 검수: 자동 검사 → Grok·Gemini 교차 검수(지적만) → 반영, 원어민 검수 전 `draft`. 프롬프트·결과는 `docs/dialogue_review/` 에 남긴다.

## 6. 톤 — 카오스·재미·심쿵을 많이 (사용자 지시 2026-11-03)

- 편마다 **웃음 또는 설렘이 터지는 순간**을 넣는다: 엉뚱한 오해, 말실수와 정정, 과장된 반응, 갑작스러운 설렘, 여자 쪽이 먼저 던지는 플러팅, 앞 편을 받는 콜백 개그.
- 원칙의 「반전 1회」(`twist`)는 최소치 — 짧은 편에도 킥을 아끼지 않는다.
- 교과서체·설명 대사·다짐이나 감사로 끝내기 금지. 마지막 턴은 웃음이나 여운(다음 편 떡밥).
- Grok 재작성 요청에도 "카오스·재미·심쿵을 더 세게"를 명시하고, 장면 그림도 표정·상황이 웃기거나 설레게.
- 수위는 원칙 §10(12+) 안에서.

### 6-1. 반전 비율 기준 (사용자 지시 2026-11-03, 모든 언어앱 공통 — 한국어앱 세션 경유)

- **카오스(일이 걷잡을 수 없이 커지는 반전) = 전체의 30% 이상**(앱당 ~250편이면 75편+). 예: 「네」만 했더니 점원이 봉투·영수증·적립·1+1까지 / 「아무거나」 시켰더니 음식이 전부 나옴 / 하트 세 개를 단톡방에 보냄 / 셀카 한 장에 지나가던 사람·강아지까지 / 깜짝 파티가 다 망했는데 제일 좋은 생일. 인도네시아 장면 예: 오젝 기사가 길을 「잘 안다」더니 동네 투어가 됨, 와룽에서 「pedas sedikit(조금만 맵게)」가 삼발 폭탄이 됨, 단톡방(WA 그룹)에 잘못 보낸 음성 메시지.
- **심쿵**: 연애·플러팅 편은 편마다 심쿵 한 줄(마음을 들키는 말·말끝 흐리기·여운), 다른 주제에도 가끔. **여성이 먼저 다가가는 편을 더 많이.**
- 편마다 `twist_type`: `chaos` · `slip`(말실수) · `reveal`(의외 사실) · `emotion`(갑작스러운 감정) · `ignore`(무시·엇박자). **묶음(레벨·주제)마다 비율을 검사기로 확인**한다.
- 기존 편을 고칠 때는 끝 2~4턴만 카오스로 바꾸고, 바뀐 대화 쌍의 컷만 다시 그린다.
- 참고: 한국어앱 `~/talkverse/ko/assets/data/dialogues/`(96편, 카오스 27%), 반전 고친 예 커밋 `a2e8eb9`.

## 7. 절벽 R1 토큰 채우기와 Grok 재작성 「꼭 남길 낱말」 (2026-11-03 밤)

- 절벽은 어근+접사 토큰으로 다시 셌다(인도네시아 제작 686편, R1 104 · R2 139 · R3 249 · R4 523, 도구 `tools/corpus/`). 회화 낱말을 같은 분석기로 쪼개 R1 토큰이 몇 개 나오는지 본다.
- Grok 재작성은 표준형을 구어형으로 바꾼다(tidak→nggak, sudah→udah, saja→aja, seperti→kayak, lihat→liat, -mu→kamu). 구어형도 R1 이지만 표준형 R1 이 회화에서 빠진다.
  → 편 JSON 에 `keep`(남길 낱말 목록)을 두면 `tools/grok_rewrite_id.py` 가 요청문에 「꼭 남길 낱말 — 표준형 그대로」 줄을 넣는다. 4차부터 적용, 효과 확인.
- 받은 재작성은 그대로 쓰지 않는다: `tools/fix_turns.py <편> "<사유>" 번호="인니어|한국어"` 로 고치고 사유는 `review.final` 에. 자주 고친 것 — 호칭 음역(Kak→「카크」), 채팅체 wkwk 를 말에, 앞뒤 논리 깨짐, 8단어 초과, 한국어 말투 섞임.
- 결과(2026-11-03): R1 24편, 카오스 58%, R1 104 토큰 전부 등장, 회화 토큰의 R1 비율 51%.
- 5차(2026-11-04 새벽, `tools/write_r1_batch5.py`): 1~2회만 나온 R1 토큰(dan·kalau·harus·dengan·maaf·siapa·bagaimana·mereka·kami·kalian·tak·ayo·sekali) 위주로 6편, 반전 유형 reveal·ignore 추가.
  → R1 30편, 카오스 57%(chaos 17·emotion 6·slip 4·ignore 2·reveal 1), 회화 토큰의 R1 비율 53%. 컷 120장.
  장면 컷 검수에서 자주 걸린 것: 시트에 없는 조연(교수·기사)이 컷마다 바뀜 → redo 문구에 생김새를 글로 고정, 「라벨·말풍선 넣지 말 것」이라고 쓰면 오히려 그려 넣음 → "인물과 배경만 있는 순수한 그림"으로.
