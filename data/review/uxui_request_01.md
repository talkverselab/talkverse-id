[UX01] 한국인을 위한 인도네시아어 학습 앱 「인도네시아어유니버스」의 아이패드 UX/UI 시안을 부탁합니다. **글 시안 1개 + 그림 1장**만 주세요.

## 앱 소개(지금 상태)
- 인도네시아어는 라틴 문자. 이 앱의 축은 **접사(meN-·ber-·di-·-kan…)와 어근(kata dasar)** — 어근 하나에 접사를 붙여 파생어 가족을 연다. 말레이어(MS)와의 차이도 토글로 보여 준다.
- 메뉴: 회화 · 접사 · 어근 · 빈도 단어 · 인니어↔말레이어 · 복습 카드. 탭은 홈 · 학습 · 진행 · 프로필.
- 아이패드(가로 720 이상)는 왼쪽 레일 + 왼쪽 칸(탭 목록) | 오른쪽 칸(고른 화면). 회화는 「만화책 읽기형」: 위 장면 컷(말풍선) + 현재 문장 캡션 + 대화 스크립트 + 하단 재생·속도·자막 칩(인도네시아어 고정 / 단어 뜻 / 한국어). 첨부 3번째 그림이 지금 화면.
- 회화 한 줄 예: `Halo! Apa kabar?` — 한국어 「안녕하세요! 잘 지내세요?」 — 단어 뜻 `halo=안녕 apa=무엇 kabar=소식`.

## 톤(바꾸지 말 것)
- 흰 바탕 · 남색 #0A2540 글자 · 인도네시아어 강조색 테라코타 #B4512F → #C9917F 그라데이션(버튼·현재 턴·성과) · 인디고 #635BFF(선택·보조) · 선 #E6EBF1 · 보조 글자 #6B7C93. 홈 상단에는 파스텔 메시(복숭아·분홍·라벤더·하늘 번진 원).
- 그림 톤 = 첨부 1·2번(부드러운 펠트·점토 인형, 파스텔 배경, 둥근 얼굴, 따뜻한 조명, **그림 안에 글자 없음**).
- 성과는 문장과 작은 막대로(편 완주·카드 맞음). 스트릭·포인트·순위는 쓰지 않는다.

## 글 시안 1개
지금 화면(첨부 3)을 기준으로, 이 앱만의 강점(접사·어근 가족, ID↔MS 차이)이 회화를 읽는 중에도 드러나는 아이패드 화면을 설계해 주세요:
1. 회화 리더에서 단어를 눌렀을 때의 「어근·접사 분해」 표시 방법(예: me+baca → membaca, 같은 어근 가족 3~5개, MS 형태가 다르면 표시).
2. 홈 · 학습 탭 왼쪽 칸 구성(오늘의 컷 / 이어서 읽기, 메뉴 6개를 어떻게 묶을지).
3. 진행 탭(성과) 한 화면 구성.
각 항목에 아이패드 가로 기준 ASCII 레이아웃 1개씩, 글자 크기·간격(8pt 그리드)·색 토큰을 적어 주세요. 한국어로.

## 그림 1장
위 1번(회화 리더 + 단어 눌러 어근·접사 분해 시트가 열린 상태)을 **아이패드 가로 한 프레임(4:3, 태블릿 1개)** 으로 그려 주세요. 장면 컷에는 첨부 톤의 점토 인형 둘(남녀)이 자카르타 카페에서 대화. UI 글자는 인도네시아어·한국어. 그림은 이 **1장만**.
